# 概要

> [!NOTE]
> Unscroll の狙い、守ること、解決したい不満、最初のリリースの機能が分かる。
> 作る順番は [roadmap](roadmap.md) にある。

スマホを触りすぎる人が、集中した分だけ相棒に日本を旅させて SNS を断つアプリである。止めたのに効かない・すぐ外せる・記録が消える、という不満を解く。

| 項目 | 内容 |
| --- | --- |
| 名前 | unscroll（英語の表記は Unscroll）。ストアの表示名は「Unscroll」 |
| 対応 | iOS 18 以上（iPhone のみ、縦向き） |
| 作る人 | 1 人。自分では使わない |

## 📏 守ること

作る時に、次の決まりを守る。

> [!IMPORTANT]
> - 最初のリリースは課金しない
> - 使用時間と記録は端末の中に置き、サーバーを持たない
> - 名所の絵は自分の絵柄で描く。新しい建物とご当地キャラは入れない

## 😣 解決したい不満

競合 8 本のレビューから集めた不満と、それに応える機能である。重さは 🔴 高、🟠 中、🟡 低で書く。

| 不満 | 出た競合 | 重さ | 対応する機能 |
| --- | --- | --- | --- |
| 時間どおりに止まらない・戻らない | 5 本 | 🔴 高 | 旅の時間を OS の見張りに任せ、今の状態を画面に出す |
| すぐ外せる・子どもが外せる | 4 本 | 🔴 高 | 外しにくさを 3 段階から選ぶ |
| 毎回アプリを選ぶ手間 | 6 本 | 🔴 高 | 選んだアプリを保存し、いつでも変えられる |
| 記録や育てたものが消える | 3 本 | 🔴 高 | 進んだ距離と絵はがきを端末の DB に置き、閉じても消えない |
| 広告と課金の押し付け | 5 本 | 🔴 高 | 広告を入れず、最初は課金しない |
| 寝落ちで時間がずれる | 3 本 | 🟠 中 | 旅は長さを決めて始める |

> [!WARNING]
> レビューは各競合のページの先頭 10 件だけで、星の数は分からなかった。件数は少なめに見ている。

## ✨ 最初のリリースの機能

最初のリリースは、Screen Time API と端末の DB だけを使い、通信をしない。

| 機能 | 中身 |
| --- | --- |
| 旅 | 長さを決めて始めると、選んだアプリを止め、1 分の集中で 1 km 進む。閉じても続き、終われば戻る |
| 道のり | 東京から京都まで約 500 km。日本橋・芦ノ湖・三保の松原・浜名湖・名古屋城・琵琶湖・清水寺の 7 か所 |
| 絵はがき | 名所に着くと、その場所の絵はがきとおみやげが届く。部屋に飾り、図鑑が埋まる |
| 相棒 | ペンギン・たぬき・黒柴から選ぶ。毛の色を 4 つから選び、名前を付ける |
| 止めるアプリ | 選んだアプリを保存し、SNS・動画のまとまりで選べる |
| 外しにくさ | やさしい（1 分だけ開ける）・ふつう（10 秒待つ）・きびしい（終わるまで開けない） |
| 止めた画面 | SNS を開くと、相棒から「まだ帰らないよ」と手紙が届く |
| 今日の使用時間 | OS が描く枠で出す |
