# 概要

> [!NOTE]
> おるすマホの狙い、守ること、解決したい不満、最初のリリースの機能が分かる。
> 作る順番は [roadmap](roadmap.md) にある。

スマホを触りすぎる人が、集中した分だけ相棒に日本を旅させて SNS を断つアプリである。止めたのに効かない・すぐ外せる・記録が消える、という不満を解く。

| 項目 | 内容 |
| --- | --- |
| 名前 | おるすマホ（スマホにお留守番を頼んで旅に出る）。リポジトリとコードの名前は unscroll のまま |
| 対応 | iOS 18 以上（iPhone のみ、縦向き） |
| 作る人 | 1 人。自分では使わない |

## 📏 守ること

作る時に、次の決まりを守る。

> [!IMPORTANT]
> - 最初のリリースは課金しない
> - 使用時間と記録は端末の中に置き、サーバーを持たない
> - 名所の絵はコードでドット絵に描く。新しい建物とご当地キャラは入れない。描き方は[名所の決定](decisions/landmark.md)にある

## 😣 解決したい不満

競合 8 本のレビューから集めた不満と、それに応える機能である。重さは 🔴 高、🟠 中、🟡 低で書く。

| 不満 | 出た競合 | 重さ | 対応する機能 |
| --- | --- | --- | --- |
| 時間どおりに止まらない・戻らない | 5 本 | 🔴 高 | 旅の時間を OS の見張りに任せ、今の状態を画面に出す |
| すぐ外せる・子どもが外せる | 4 本 | 🔴 高 | 外しにくさを 3 段階から選ぶ |
| 毎回アプリを選ぶ手間 | 6 本 | 🔴 高 | 選んだアプリを保存し、いつでも変えられる |
| 記録や育てたものが消える | 3 本 | 🔴 高 | 進んだ距離と絵はがきを端末の DB に置き、閉じても消えない |
| 広告と課金の押し付け | 5 本 | 🔴 高 | 広告を入れず、最初は課金しない |
| 寝落ちで時間がずれる | 3 本 | 🟠 中 | 旅は長さを決めて始める |

> [!WARNING]
> レビューは各競合のページの先頭 10 件だけで、星の数は分からなかった。件数は少なめに見ている。

## ✨ 最初のリリースの機能

最初のリリースは、Screen Time API と端末の DB だけを使い、通信をしない。

| 機能 | 中身 |
| --- | --- |
| アイコンと起動 | アイコンは、ナイトキャップで眠るスマホと、開いた扉の先へ続く朝の道。起動の画面では、選んだ相棒が夜明けの地平線でひと跳ねする |
| 最初の導線 | 初めて開いた時に、説明 4 枚と支度 3 枚を出す。説明は旅・道のり・絵はがき・今日の使用時間で、支度は相棒・許可・止めるアプリ |
| 旅 | 長さを 5 分から 3 時間で、つまみか 6 つの札で選ぶ。始めると選んだアプリを止めて 1 分で 1 km 進み、閉じても続き、終われば戻る |
| 道のり | [道のりの一覧](#道のりの一覧)の 7 本で、どれも無料。旅に出ていない間は地図のタブから替えられ、進んだ km は道のりごとに残る |
| 絵はがき | 名所に着くと、その場所の絵はがきと、ご当地の食べ物のおみやげが届く。絵はがきを部屋に飾り、図鑑が埋まる |
| 模様替え | 部屋の壁を 4 種から、床を 3 種から選ぶ。飾る絵はがきを 2 枚（道のりを終えたら 3 枚）まで選び、押した順に左から吊るす |
| 相棒 | ペンギン・たぬき・柴犬から選ぶ。毛の色を種ごとの 4 つから選び、名前を付ける。初めは灰（子）のペンギン |
| 止めるアプリ | 選んだアプリを保存し、SNS・動画のまとまりで選べる |
| 外しにくさ | やさしい（1 分だけ開ける）・ふつう（10 秒待つ）・きびしい（終わるまで開けない） |
| 止めた画面 | SNS を開くと、相棒から「まだ帰らないよ」と手紙が届く。中身は[止めた画面の決定](decisions/shield.md)にある |
| 今日の使用時間 | OS が描く枠で、合計と昨日の同じ時刻との差・時間ごとの棒・種類ごとの内訳を出す。手に取った回数・最初に見た時刻・通知の件数・上位 3 つのアプリと、旅の km に直した一言も添える |

### 道のりの一覧

km は、1 分の集中で 1 km 進む決まりで数える。名所ごとに、絵はがきとおみやげの絵を描く。

| 道のり | km | 名所 |
| --- | --- | --- |
| 東京 → 京都 | 500 | 日本橋・芦ノ湖・三保の松原・浜名湖・名古屋城・琵琶湖・清水寺 |
| 東北新幹線 駅弁の旅 | 714 | 東京駅・宇都宮駅・仙台駅・盛岡駅・八戸駅・新青森駅 |
| 沖縄めぐり | 140 | 那覇空港・首里城・斎場御嶽・万座毛・備瀬のフクギ並木・古宇利島 |
| 日本の世界遺産めぐり | 1,250 | 日光の社寺・富岡製糸場・富士山・白川郷・古都奈良・姫路城・厳島神社 |
| 大阪 → 博多 食べ歩き | 570 | 道頓堀・神戸の南京町・明石・岡山・尾道・広島・博多の屋台 |
| 函館 → 旭川 | 500 | 函館・大沼・洞爺湖・小樽・札幌・富良野・旭川 |

遊園地など、会社が持つ場所の名前とキャラクターは使わない。駅弁は料理の名前で書き、売る会社や商品の名前は使わない。
