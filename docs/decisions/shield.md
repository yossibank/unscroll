# 止めた画面の決定

> [!NOTE]
> 止めた画面の中身と、外しにくさごとの開き方の決定と、その理由が分かる。
> 外しにくさと止めた画面の機能は [overview](../overview.md#-最初のリリースの機能) にある。

## 止めた画面の手紙

**決定：止めた画面は、相棒の絵と、次の名所までの残りの距離を書いた手紙にする**

| 項目 | 内容 |
| --- | --- |
| 理由 | 止めた画面は OS の枠で、絵 1 枚・題・本文・ボタン 2 つしか描けない |
| 理由 | 残りの距離があると、旅の途中の画面と同じ数字で、戻る気になる |
| 却下 | アプリ名と「まだ帰らないよ」だけの決まった文。旅とのつながりが見えない |

> [!IMPORTANT]
> - 絵は、選んだ相棒の種と毛の色のドット絵にする。
> - 題は「<名前>から手紙が届いたよ」にする。
> - 本文は「まだ帰らないよ」に、次の名所と残りの距離と「いっしょに行こう」を続ける。
> - 上のボタンは「旅に戻る」にし、押すと止めた画面を閉じる。

## 外しにくさごとの開き方

**決定：下のボタンで 1 分だけ開け、ふつうは 2 回押す形で 10 秒待たせる**

| 外しにくさ | 下のボタン | 押した時 |
| --- | --- | --- |
| やさしい | 1 分だけ開く | 1 分開く |
| ふつう | 10 秒待って開く | 1 回目は「10 秒後にもう一度押してね」に変わる。10 秒たって押すと 1 分開く |
| きびしい | 無し | |

| 項目 | 内容 |
| --- | --- |
| 理由 | 止めた画面では時計を動かせない。押した時刻を覚えて、2 回目で比べる |
| 却下 | ふつうは待たせず、1 日に開ける回数を 3 回までにする形。overview の「10 秒待つ」から離れる |

> [!WARNING]
> 押した後に止めた画面が描き直されるかと、1 分後に止め直せるかは未検証である。実機で確かめる。

## 外しにくさを変える時

**決定：外しにくさは、旅の途中に変えられない**

| 項目 | 内容 |
| --- | --- |
| 理由 | 途中で緩められると、外しにくさが意味を持たない |
| 却下 | 途中でも、今より厳しい方にだけ変えられる形。画面の決まりが増える |

> [!IMPORTANT]
> 旅の途中は、設定の外しにくさを灰色にし「旅が終わったら変えられます」と出す。旅は、始めた時の外しにくさで最後まで止める。

## 開いた時の旅

**決定：止めたアプリを 1 分開いても、旅と距離は変えない**

| 項目 | 内容 |
| --- | --- |
| 理由 | 叱らない作りにそろえる。開ける形を選んだのは本人である |
| 却下 | 開いた 1 分を距離に数えず、旅の結果に寄り道の回数を出す形 |
