# 止めた画面の決定

> [!NOTE]
> 止めた画面の中身と、外しにくさごとの開き方の決定と、その理由が分かる。
> 外しにくさと止めた画面の機能は [overview](../overview.md#-最初のリリースの機能) にある。

## 止めた画面の手紙

**決定：止めた画面は、相棒の絵と、旅の残りの分だけを書いた短い手紙にする**

| 項目 | 内容 |
| --- | --- |
| 理由 | 止めた画面は OS の枠で、絵 1 枚・題・本文・ボタン 2 つしか描けない |
| 理由 | 開いてすぐ閉じる画面なので、2 行で読み切れる方が戻る気になる |
| 却下 | 今いる名所と次の名所までの距離も書く長い手紙。行が多く、読まれない |
| 却下 | 残りの分を開いている間に数え直す形。OS は枠を開いた時に組み、後から描き直させる手段が無い |

> [!IMPORTANT]
> - 絵は、選んだ相棒の種と毛の色のドット絵に、ドット絵の封筒を重ねる。
> - 題は「<名前>より」にする。相棒が読めない時は「旅先からの手紙」にする。
> - 本文は「旅はあと N 分」と「スマホはお休みしててね。」の 2 行にする。残りの分が読めない時の 1 行目は「旅の途中だよ」にする。
> - 色はアプリにそろえ、背景を紙の色、字を墨の色にする。上のボタンは青緑にし、下のボタンの字は白にする。
> - 上のボタンは「旅に戻る」にし、押すと止めた画面を閉じる。ボタンの幅は OS が決めるため、名前を入れると 2 行に折れる。
> - 止めた画面は、データベースを開かずに App Group の控え（`ShieldSnapshot`）を読む。止めた画面の拡張は App Group に書けず、WAL のデータベースを開けない。
> - 控えには、相棒・道のり・終わった旅の距離・旅の始まりと長さを書く。部屋の画面を読み直すたびに書き、旅が終わったら消す。

## 外しにくさごとの開き方

**決定：下のボタンで 1 分だけ開け、ふつうは 2 回押す形で 10 秒待たせる**

| 外しにくさ | 下のボタン | 押した時 |
| --- | --- | --- |
| やさしい | 1 分だけ開く | 1 分開く |
| ふつう | 10 秒待って開く | 1 回目は「10 秒後にもう一度押してね」に変わる。10 秒たって押すと 1 分開く |
| きびしい | 無し | |

| 項目 | 内容 |
| --- | --- |
| 理由 | 止めた画面では時計を動かせない。押した時刻を覚えて、2 回目で比べる |
| 却下 | ふつうは待たせず、1 日に開ける回数を 3 回までにする形。overview の「10 秒待つ」から離れる |
| 却下 | 止めたものを、すべてまとめて 1 分外す形。押していないアプリやカテゴリまで開けてしまう |

> [!IMPORTANT]
> - アプリやサイトを 1 つずつ選んで止めた時は、押したものだけを 1 分開く。
> - カテゴリでまとめて止めたアプリは、そのカテゴリごと 1 分開く。ボタンの拡張にアプリが渡らず、止めた画面の拡張は App Group に書けないため。
> - 押した時刻は、押したアプリかカテゴリごとに覚える。押してから 60 秒を過ぎたら、待ちを始め直す。

## 外しにくさを変える時

**決定：外しにくさは、旅の途中に変えられない**

| 項目 | 内容 |
| --- | --- |
| 理由 | 途中で緩められると、外しにくさが意味を持たない |
| 却下 | 途中でも、今より厳しい方にだけ変えられる形。画面の決まりが増える |

> [!IMPORTANT]
> 旅の途中は、設定の外しにくさを灰色にし「旅が終わったら変えられます」と出す。旅は、始めた時の外しにくさで最後まで止める。

## 開いた時の旅

**決定：止めたアプリを 1 分開いても、旅と距離は変えない**

| 項目 | 内容 |
| --- | --- |
| 理由 | 叱らない作りにそろえる。開ける形を選んだのは本人である |
| 却下 | 開いた 1 分を距離に数えず、旅の結果に寄り道の回数を出す形 |
