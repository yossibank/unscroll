# 名所の決定

> [!NOTE]
> 名所の絵はがきと、名所で届くおみやげの描き方の決定と、その理由が分かる。
> 名所の機能は [overview](../overview.md#-最初のリリースの機能) に、相棒の絵は[相棒の決定](companion.md)にある。

## 名所の絵

**決定：名所は、コードで描くドット絵にし、山・水・建物を名所ごとに描き分ける**

| 項目 | 内容 |
| --- | --- |
| 理由 | 相棒と同じドット絵なので、絵柄がそろう。空の色を時刻で替え、景色を流して動かせる |
| 理由 | 自分で描くので、名所を足しても料金と権利の確認が要らない |
| 却下 | 無料で使える写真（CC0）。名所を足すたびに、写真を探して権利を確かめる手間とおそれが残る |
| 却下 | 広重などの浮世絵。東海道の外の道のりと、名古屋城・清水寺の絵が無い |
| 却下 | AI で作った絵。使ってよいかが分からない |
| 却下 | なめらかな形とグラデーションの切り絵。ドット絵の相棒だけが浮く |
| 却下 | 山・水・松の部品を、色違いで使い回す形。どの名所も同じ景色に見える |

> [!IMPORTANT]
> - 絵はがきは 160×100 px で描き、拡大しても点をぼかさない
> - 名所ごとに主役と時刻を決め、その名所でしか見えない形を 1 つ以上入れる
> - 同じ山でも、名所ごとに見え方を変える。芦ノ湖の富士山は奥に小さく、三保の松原の富士山は海越しに大きく描く
> - 名所ごとに替えないのは、空の色の段・時刻の光の色・相棒の貼り方だけにする

| 名所 | 時刻 | 主役 | その名所らしさ |
| --- | --- | --- | --- |
| 日本橋 | 朝 | 石造りの二連のアーチ橋 | 水に映って眼鏡の形になるアーチ、中央の飾りの街灯、蔵の街並み。首都高は描かない |
| 芦ノ湖 | 昼 | 外輪山に囲まれた湖 | 奥の小さな富士山、帆船の遊覧船、湖畔の鳥居 |
| 三保の松原 | 昼 | 海越しの大きな富士山 | 白い波打ち際と砂浜、曲がった幹の松 |
| 浜名湖 | 夕方 | 湖の中の大鳥居 | 夕日と水面の光の筋、海苔の竹の柵、遠くの橋 |
| 名古屋城 | 夕方 | 五層の天守 | 金のしゃちほこ、緑青の屋根、裾の広がる石垣、堀 |
| 琵琶湖 | 朝 | 水平線まで続く湖 | 比良の山並み、湖の中の鳥居、白い帆の舟、葦 |

## おみやげ

**決定：おみやげは、名所のご当地の食べ物にし、陰と照りのある 48×48 px のドット絵で描く**

| 項目 | 内容 |
| --- | --- |
| 理由 | 食べ物は、見て楽しく、届くのを待ちたくなる |
| 理由 | 光の当たり方を計算して陰と照りを付けると、ドット絵でも美味しそうに見える |
| 却下 | 寄木細工や置物などの工芸品。食べ物より楽しさが弱い |
| 却下 | 32×32 px の平らな絵。米粒や焼き目が描けず、美味しそうに見えない |
| 却下 | 食べ物に目とほっぺの顔を付ける形。気味が悪い |

> [!IMPORTANT]
> - 食べ物に顔を付けない
> - 縁取りは相棒と同じ濃い茶にし、光は左上から当てる
> - タレ・殻・釉薬のような艶のある所には、白い照りを入れる
