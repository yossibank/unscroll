# 相棒の決定

> [!NOTE]
> 相棒の絵の作り方と動かし方の決定と、その理由が分かる。
> 相棒の機能は [overview](../overview.md#-最初のリリースの機能) にある。

## 相棒の絵

**決定：相棒は、コードで描いたドット絵を名所の絵にシールとして重ね、場面ごとに絵を替えて動かす**

| 項目 | 内容 |
| --- | --- |
| 理由 | 名所は写実的に見せる。絵柄の違う相棒も、白い縁で貼ったものに見せれば浮かない |
| 理由 | 自分で描くので、絵の権利がはっきりする。9 枚の位置と光が必ずそろう |
| 却下 | Image Playground で作ったドット絵。使ってよいかが分からず、9 枚の位置と光がずれやすい |
| 却下 | 陰影を付けた柔らかい絵で、名所になじませる形。コードでは毛並みと可愛らしさが足りず、手描きか生成が要る |
| 却下 | コードで丸と三角を重ねた平らな絵。継ぎ目が見え、安っぽかった |
| 却下 | 絵を部品に分けて動かす形。切り分けと描き足しに人の手が要る |

> [!IMPORTANT]
> - 1 種あたり、歩く・左向きに歩く・まばたき・手を振る・喜ぶ・跳ぶ・眠る・驚く・すべるの 9 枚を作る
> - 9 枚は、32×32 px の同じ大きさ・同じ位置・同じ光にそろえ、背景を透明にする
> - 名所の上では、白い縁と薄い影を付け、拡大しても点をぼかさない
> - 呼吸・弾み・歩き回る動きは、コードで足す
